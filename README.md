**Building now**

- [toolnexus](https://github.com/muthuishere/toolnexus): one agent SDK, hand-ported to 8 languages (JS, Python, Go, Java, C#, Elixir, Clojure, Rust), kept honest by one conformance suite
- [aos](https://github.com/muthuishere/aos): one CLI over macOS, Windows and Linux, so an agent drives the machine the way you do
- [ctx-optimize](https://github.com/muthuishere/ctx-optimize): turns a codebase into a local knowledge graph an agent answers from. No LLM calls, no database
- [sec](https://github.com/muthuishere/sec): one vault for you, your team and your agents
- [crossmem](https://github.com/muthuishere/crossmemcli): context memory shared across local agent tools
- [routsi](https://github.com/muthuishere/routsi): OpenAI-compatible endpoint that routes each request to the right model
- [citenexus](https://github.com/muthuishere/citenexus): RAG that answers only from quoted evidence, or says it doesn't know
- [jevx](https://github.com/muthuishere/jevx): quick typed judgements (yes/no, pick one, rate) for agents
- [hand-drawn-diagrams](https://github.com/muthuishere/hand-drawn-diagrams): agent skill that draws architecture and workflow diagrams by hand, in monochrome
